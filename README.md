# ระบบจองตั๋วรถบัส (COMSCI TOUR)

โปรแกรมจองตั๋วรถบัสแบบ Desktop เขียนด้วย Java Swing เก็บข้อมูลเป็นไฟล์ CSV

│           └── AdminUi.java     ปุ่ม ฟอร์ม ตาราง ที่หน้า Admin ใช้ร่วมกัน
├── data/                        ไฟล์ข้อมูล CSV (โปรแกรมอ่าน-เขียนที่นี่)
│   ├── users.csv                สมาชิก (name,phone,password,birth_date,gender)
│   ├── routes.csv               เส้นทาง

## วิธีรัน

ต้องติดตั้ง JDK (ทดสอบกับ JDK 21 และ 25)

- **Windows:** ดับเบิลคลิก `run.bat`
- **VS Code:** เปิดโฟลเดอร์ `BusBooking` (ติดตั้ง Extension Pack for Java) แล้วรันคลาส `busbooking.Main`

ต้องรันจากโฟลเดอร์ `BusBooking` เสมอ เพราะโปรแกรมหาไฟล์ใน `data/` และ `images/` โดยเทียบจากโฟลเดอร์นี้

## การเข้าสู่ระบบ

- **ผู้โดยสาร:** ใช้เบอร์มือถือกับรหัสผ่าน (สมัครใหม่ได้ที่หน้า Sign Up ข้อมูลเก็บใน `data/users.csv`)
- **Admin:** ใช้บัญชีที่กำหนดไว้ใน `src/busbooking/ui/admin/AdminLoginFrame.java`

## การทำงานที่ควรรู้

- **ผังที่นั่ง:** วาดตามจำนวนที่นั่งของประเภทรถ แถวละ 4 ที่ (D C | ทางเดิน | B A) ชื่อที่นั่งเช่น `A1`, `D10`
  รถคันใหญ่เลื่อนดูด้านข้างได้
- **ที่นั่งว่าง (`available_seats`):** = ที่นั่งของรถ − ที่นั่งที่ถูกจอง คำนวณใหม่อัตโนมัติหลังจอง/ยกเลิก,
  เมื่อแก้จำนวนที่นั่งของประเภทรถ และทุกครั้งที่เปิดหน้าเลือกที่นั่งหรือหน้าจัดการเที่ยวรถ
  (การจองที่ไม่ชำระภายใน 15 นาทีจะคืนที่นั่งเอง) — Admin แก้ค่านี้เองไม่ได้
- **เปิดโปรแกรมหลายหน้าต่างพร้อมกัน:** การจอง/ชำระเงิน/ยกเลิก/สมัครสมาชิก ล็อกไฟล์ข้อมูลไว้ระหว่างทำงาน
  จึงจองที่นั่งเดียวกันซ้ำหรือสมัครเบอร์ซ้ำพร้อมกันไม่ได้
- **ข้อผิดพลาด:** อ่าน/เขียนไฟล์ไม่สำเร็จ (เช่น เปิดไฟล์ CSV ค้างใน Excel) จะขึ้นกล่องข้อความแจ้ง
  และไม่บันทึกทับไฟล์เดิม แถวที่อ่านไม่ได้ในไฟล์จะถูกข้ามแต่ไม่ถูกลบ
- **ลดจำนวนที่นั่งของรถ:** ทำไม่ได้ถ้ามีคนจองที่นั่งที่จะหายไปจากผัง (เช่น จอง A10 ไว้ แล้วจะลดรถ 40 ที่เหลือ 20)
- **การจองที่ไม่ชำระ:** หมดเวลาใน 15 นาที (ที่นั่งกลับมาว่าง) แสดงในประวัติว่า "หมดเวลาชำระ" อีก 24 ชั่วโมง
  แล้วจะถูกลบออกจาก `bookings.csv` ตอนมีการจองครั้งถัดไป (ไฟล์ไม่โตเรื่อยๆ และรหัสการจองไม่ถูกใช้ซ้ำ)
- **วันเกิดและเพศ:** หน้าสมัครสมาชิกบังคับกรอก บันทึกใน `users.csv` เป็นวันที่ ค.ศ. `yyyy-MM-dd` และ `MALE`/`FEMALE`
  (สมาชิกที่สมัครก่อนมีสองช่องนี้จะเป็นช่องว่าง และยังล็อกอินได้ตามปกติ)
- **ชื่อผู้โดยสาร:** ตั๋ว หน้าประวัติ หน้าชำระเงิน และหน้าสรุปของ Admin แสดงชื่อที่สมัครไว้ (รหัสผู้ใช้ในไฟล์ยังเป็นเบอร์มือถือ)
- หน้า Login ไม่มีแถบหัวหน้าต่าง ย้ายหน้าต่างได้ด้วยการลากที่พื้นหลังหรือรูป
- ตั๋วที่ออกแล้วจะถูกบันทึกเป็นไฟล์ `.txt` ใน `data/tickets/`
